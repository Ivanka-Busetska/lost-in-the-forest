# LOST IN THE FOREST

Невелика браузерна гра-головоломка. Курс «Розробка ігрових додатків», проєктна робота, частина 2.

Ти загубився в лісі. Знайди ключ, обійди колючки та лісових духів і відчини ворота.

## Як запустити

Відкрий `index.html` у браузері (Chrome, Firefox, Safari). Нічого встановлювати не потрібно.

## Керування

- Рух: стрілки або WASD. На телефоні: торкнись поля.
- Дія (взяти ключ, активувати руну, відчинити ворота): E або пробіл.
- Ривок: Shift.
- Перезапуск рівня: R.

## Версії

| Версія | Файл | Що містить |
|---|---|---|
| v0 | `v0/index.html` | Одна локація: ключ, ворота, перезапуск |
| поточна | `index.html` | Титулка, вибір рівнів, 3 рівні, колючки, духи, іскри, ривок, звук |

## Критерії приймання (v0)

1. Ключ можна підняти лише в межах 48 пікселів від нього.
2. Відчинення воріт змінює стан «замкнені» на «відчинені» один раз і лише за наявності ключа.
3. Перезапуск повертає ключ, ворота й стан до початкових значень.

## Відомі обмеження

- Колізії прості (прямокутники й кола).
- Ривок працює лише з клавіатурою.
- Прогрес рівнів зберігається у браузері, якщо він це дозволяє.
